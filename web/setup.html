1 Cloud storage

Not connected

Photos upload to a private Cloudflare R2 bucket in your own account. Guests download them from there, so they never join the booth's Wi-Fi.

How to get these details
  1. Sign in to the Cloudflare dashboard and open Storage & databases → R2.
  2. Create a bucket named piccie-photos. Leave it private.
  3. Planning a custom domain (step 2)? Also create piccie-links now, so one token can cover both buckets.
  4. On the R2 Overview page, find Account Details → API Tokens and select Manage.
  5. Create an Account API token with Object Read & Write, applied only to the bucket(s) above.
  6. Copy the Account ID, Access Key ID and Secret Access Key below. Cloudflare shows the secret only once.

2 Custom domain Optional

Off

Without a domain, guest links are long and last 7 days, so the QR code on screen is dense. Your own domain makes short links (a smaller, easier QR code) that don't expire. A domain costs about $5–10 a year.

How to connect a domain
  1. In Cloudflare, open Domain Registration → Register Domains and buy a domain. It must be in the same Cloudflare account as your buckets. A domain bought elsewhere works after you move its DNS to Cloudflare.
  2. Create a second bucket, such as piccie-links. Never connect a domain to piccie-photos.
  3. Open R2 → piccie-links → Settings → Custom Domains, select Add, enter the domain or a subdomain such as photos.example.com, and wait until it shows Active.
  4. Your R2 token must cover both buckets. If it only covers piccie-photos, create a new one and replace the keys in step 1.

Piccie checks that the domain serves only piccie-links before turning it on. Photos there get random names that can't be guessed, and deleting a strip or event on the booth removes them. Avoid spam-heavy endings such as .bid or .win; phones and venue networks often block them.
