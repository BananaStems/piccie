# PICCIE CLOUDFLARE R2 SETUP
#
# After flashing the Piccie image, complete this file and make sure it is at the
# top level of the microSD boot drive before first boot. You can edit the blank
# file on the drive or copy a completed file onto it. Keep the filename exactly
# "piccie-r2.txt". Do not change the names to the left of "=".
#
# 1. Sign in to https://dash.cloudflare.com/
# 2. Open Storage & databases > R2 and create a bucket named "piccie-photos".
# 3. Return to R2 Overview. Beside Account Details > API Tokens, select Manage.
# 4. Create an Account API token with "Object Read & Write" permission and
#    restrict it to only the "piccie-photos" bucket.
# 5. Copy the Account ID, Access Key ID and Secret Access Key below. Cloudflare
#    shows the secret only once.
# 6. Save or copy this completed file to the microSD boot drive, confirm it is
#    present, then safely eject the card and power on Piccie.
# 7. Choose the Wi-Fi network and enter its password on Piccie's touchscreen.
#    Do not add Wi-Fi credentials to this file.
# 8. Piccie imports the R2 credentials and removes this readable copy. If import
#    fails, shut down and read piccie-r2-status.txt on this same drive for the
#    exact field to correct.
#
# Keep these credentials private. Anyone with them can access this R2 bucket.
# The bucket stays private. Piccie creates time-limited guest download links.
